# YOUGA — site vitrine

Site statique responsive conçu à partir de la charte graphique YOUGA.

## Fichiers
- `index.html` : structure et contenus du site
- `styles.css` : identité visuelle et responsive design
- `script.js` : menu mobile et année automatique
- `assets/youga-logo.png` : logo de présentation

## Avant publication
1. Remplacer les trois maquettes de projets par les véritables rendus et photos de YOUGA.
2. Remplacer `221XXXXXXXXX` dans le lien WhatsApp par le numéro professionnel au format international, sans `+` ni espaces.
3. Vérifier le titre professionnel, les prestations et les coordonnées exactes de YOUGA.
4. Ajouter les liens e-mail et réseaux sociaux si souhaité.

## Publication gratuite
Le projet est un site HTML/CSS/JavaScript statique. Pour le publier gratuitement, créer un dépôt GitHub puis le connecter à Cloudflare Pages. Choisir le déploiement depuis le dépôt Git, sans commande de build et avec `/` comme répertoire de sortie.
